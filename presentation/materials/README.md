# Materiali originali del team

`originals/` conserva le 6 fotografie e i 10 video telefonici, spostati dalla
precedente cartella `materiale_per_video/` senza modificare i contenuti.

La registrazione originale dello schermo ha una sola copia canonica:
[`public/footage/dashboard.mp4`](../public/footage/dashboard.mp4).
È identica byte per byte al precedente file
`materiale_per_video/Registrazione 2026-10-11 151111.mp4` (SHA-256 nel
[manifest del riordino](../../docs/archive/REPOSITORY_CLEANUP_20261017.json)).

Le clip ritagliate o convertite in `public/` servono al rendering e possono
differire dagli originali per formato, risoluzione o durata. Non sono state
eliminate come se fossero copie identiche.
